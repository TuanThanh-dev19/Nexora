## 8. Chỉ mục file code đã chạm và bằng chứng

Chỉ mục dưới đây được tạo từ **patch trực tiếp**, không lấy file trong merge commit. Chỉ liệt kê source production hiện còn trong HEAD; test/config/schema xem bằng `git show --name-status <SHA>` ở bảng trên. `A` = thêm file tại commit đó; `M` = sửa. Rename được nhìn như delete/add khi thống kê; A không tự chứng minh tự viết lại toàn bộ nội dung. Commit khởi tạo `4ad7654` và đổi cấu trúc `e173198` có nhiều starter code. Muốn nhận một function cụ thể, mở diff/blame thay vì dùng danh mục chạm file này làm ownership toàn bộ.
