## Information Needed For Task Assignment

- Member names and actual role/decision authority.
- Skill rating or recent experience for Java/Spring, React, SQL Server, testing and Git/CI.
- Weekly hours and unavailable dates for the remaining project period.
- Preferred modules and learning goals.
- Known blockers, equipment/environment constraints and pairing needs.
- Definition of issue size (hours/story points) and maximum parallel work.
- Who reviews backend, frontend, schema and security changes.
- Confirmed module ownership and backup owner.
- Sprint/week dates, final deadline, demo date and external checkpoints.
- Whether tasks should optimize speed, balanced workload or learning exposure.

## Suggested Assignment Inputs for AI

Before AI assigns an issue, provide at least:

| Input | Why it matters |
|---|---|
| Issue dependency and acceptance criteria | Prevents assigning blocked/ambiguous work |
| Required skills | Matches task to capability |
| Estimate and risk | Controls workload and review needs |
| Member availability/current WIP | Avoids overload |
| Code ownership/reviewer | Reduces integration conflicts |
| Parallelization boundary | Allows independent vertical slices |
